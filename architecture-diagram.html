2. 事件绑定流程 init.js → events.js → DOM

启动流程：app.js 调用 App.core_init.init() → doInit() 先收集所有 DOM 元素到 App.dom.*，再调用 App.core_events.bindEvents() 注册全部事件监听器。 

sequenceDiagram
    participant HTML as index.html
    participant APP as app.js
    participant INIT as init.js (doInit)
    participant DOM as App.dom.*
    participant EVENTS as events.js (bindEvents)
    participant EL as DOM Elements

    HTML->>APP: 最后加载 app.js
    APP->>INIT: App.core_init.init()
    INIT->>INIT: DOMContentLoaded 就绪?
    INIT->>DOM: 收集 50+ DOM 元素引用
    Note over INIT,DOM: editor, sidebar, preview, dialog, etc.
    INIT->>EVENTS: App.core_events.bindEvents()
    EVENTS->>EL: 注册 click / keydown / input / paste 事件
    Note over EVENTS,EL: editor.addEventListener('keydown', handleEditorKeydown)
    EVENTS->>EL: 注册 contextmenu / dialog 事件
    EVENTS->>EL: 注册 zoom / theme / sidebar 切换事件
    EVENTS-->>INIT: 事件绑定完成
    INIT->>INIT: theme.restoreUserSettings()
    INIT->>INIT: updateOutline() / renderRecentFiles()
    INIT-->>APP: 初始化完成

4. getLineInfo() 光标行信息计算 code-block.js — 核心函数

该函数判断光标在代码块中的行号、是否首行/末行、是否行首/行尾。红框部分为本次修复新增的 ELEMENT_NODE 边界处理逻辑。 

flowchart TD
    GLI_START(["getLineInfo(cb, cursorNode, cursorOffset)"]) --> FIND_CODE["codeEl = cb.querySelector('code') || cb"]

    FIND_CODE --> CHECK_ELEM{"cursorNode 是
ELEMENT_NODE
且在 codeEl 内部?"}

    CHECK_ELEM -->|"是 (offset===0)"| FIND_FIRST["遍历 codeEl.firstChild"]
    FIND_FIRST --> FIRST_TEXT{"找到 TEXT_NODE?"}
    FIRST_TEXT -->|是| RESOLVE_START["修正 cursorNode=该文本
cursorOffset=0"]
    FIRST_TEXT -->|否(BR)"| RET_START["返回: isFirstLine=true
isAtLineStart=true"]

    CHECK_ELEM -->|"是 (offset>=childCount)"| FIND_LAST["遍历 codeEl.lastChild"]
    FIND_LAST --> LAST_TEXT{"找到 TEXT_NODE?"}
    LAST_TEXT -->|是| RESOLVE_END["修正 cursorNode=该文本
cursorOffset=text.length"]
    LAST_TEXT -->|否(BR)"| RET_END["返回: isLastLine=true
isAtLineEnd=true"]

    CHECK_ELEM -->|否| PASS1["第一遍遍历: 统计 hasBr / totalTextLen"]

    RESOLVE_START --> PASS1
    RESOLVE_END --> PASS1

    PASS1 --> PASS2["第二遍遍历: 定位光标所在行"]
    PASS2 --> CHILD_LOOP{"遍历 codeEl 每个 child"}
    CHILD_LOOP -->|"child === cursorNode
或 child.contains(cursorNode)"| FOUND["foundCursor = true"]
    CHILD_LOOP -->|"BR 节点"| BR_CHECK{"foundCursor?"}
    BR_CHECK -->|是| BR_FOUND["当前就是最后一行→跳出"]
    BR_CHECK -->|否| BR_ADV["lineNumber++
isFirstLine = false"]
    CHILD_LOOP -->|"TEXT_NODE"| TXT_CHECK{"foundCursor?"}
    TXT_CHECK -->|是| CALC_POS["isAtLineEnd = offset>=textLen
isAtLineStart = offset===0"]
    TXT_CHECK -->|否| TXT_NEXT["charCount += textLen"]

    FOUND --> CHILD_LOOP
    BR_FOUND --> POST
    BR_ADV --> CHILD_LOOP
    CALC_POS --> CHILD_LOOP
    TXT_NEXT --> CHILD_LOOP

    CHILD_LOOP -->|遍历完毕| POST["后处理"]

    POST --> NOBR{"!hasBr?"}
    NOBR -->|是| NOBR_FIX["isFirstLine=true, isLastLine=true

isAtLineStart / isAtLineEnd"]
    NOBR -->|否| NOBR_NOT{"!foundCursor?"}
    NOBR_NOT -->|是| SET_END["isAtLineEnd = true"]
    NOBR_NOT -->|否| DONE

    NOBR_FIX --> DONE
    SET_END --> DONE

isLastLine, isAtLineStart,

5. exitCodeBlock() 退出逻辑 code-block.js

从代码块退出到前/后段落。使用 isExitingCodeBlock 互斥锁 + try-finally 保证状态释放。 

flowchart TD
    EXIT_START(["exitCodeBlock(codeBlock, direction)"]) --> CHECK_RANGE{"selection.rangeCount?"}
    CHECK_RANGE -->|0| RETURN_E([return])
    CHECK_RANGE -->|>0| CHECK_LOCK{"isExitingCodeBlock?"}
    CHECK_LOCK -->|true| RETURN_E
    CHECK_LOCK -->|false| SET_LOCK["isExitingCodeBlock = true"]

    SET_LOCK --> TRY["try {"]
    TRY --> FIND_WRAP["wrapper = codeBlock.closest('.code-block-wrapper')"]
    FIND_WRAP --> CLEAN_BR["清理 codeEl 末尾多余 BR"]
    CLEAN_BR --> DIR{"direction?"}

    DIR -->|"after"| CHECK_NEXT{"wrapper.nextSibling?"}
    CHECK_NEXT -->|存在| SET_AFTER["setStartAfter(wrapper)"]
    CHECK_NEXT -->|不存在| NEW_P["创建 <p><br></p>
appendChild 到 editor"]

    DIR -->|"before"| CHECK_PREV{"wrapper.previousSibling?"}
    CHECK_PREV -->|存在| SET_AFTER_PREV["setStartAfter(wrapper.previousSibling)"]
    CHECK_PREV -->|不存在| NEW_P_PREV["创建 <p><br></p>
insertBefore wrapper"]

    SET_AFTER --> FOCUS["更新 selection 到新位置"]
    NEW_P --> FOCUS
    SET_AFTER_PREV --> FOCUS
    NEW_P_PREV --> FOCUS

    FOCUS --> FINALLY["finally {"]
    FINALLY --> UNLOCK["isExitingCodeBlock = false"]
    UNLOCK --> DONE_EXIT(["完成"])

6. 代码块光标退出完整调用链 端到端追踪

从用户按方向键到最终光标移出代码块的完整链路（以 ArrowDown 为例）。

    participant Browser as 浏览器
    participant Keyboard as keyboard.js

    participant CB as code-block.js

    participant Exit as code-block.js

    User->>Browser: 在代码块末尾按 ↓
    Browser->>Keyboard: keydown 事件 (ArrowDown)
    Keyboard->>Keyboard: selection.getRangeAt(0)
    Keyboard->>Keyboard: startContainer → cursorNode
    Keyboard->>Keyboard: element.closest('.code-block')

    alt 不在代码块内
        Keyboard-->>Browser: 不处理，浏览器默认行为
    else 在代码块内
        Keyboard->>Keyboard: codeContent = codeBlock.querySelector('code')
        Keyboard->>CB: getLineInfo(code, cursorNode, cursorOffset)

        rect rgb(218, 54, 51, 0.15)
            Note over CB: ★ 修复点: cursorNode 是 ELEMENT_NODE?
            alt cursorNode === codeEl && offset>=childCount
                CB-->>Keyboard: { isLastLine: true, isAtLineEnd: true }
            else cursorNode 是 text node
                CB->>CB: 遍历 childNodes 定位光标行
                CB-->>Keyboard: { isLastLine, isAtLineEnd }
            end
        end

        alt isLastLine && isAtLineEnd
            Keyboard->>Keyboard: e.preventDefault()
            Keyboard->>Exit: exitCodeBlock(codeBlock, 'after')
            Exit->>Exit: isExitingCodeBlock = true
            Exit->>DOM: 清理尾部 BR
            alt wrapper.nextSibling 存在
                Exit->>DOM: setStartAfter(wrapper)
            else wrapper 是最后一个元素
                Exit->>DOM: 创建 
 追加到 editor
            end
            Exit->>Exit: isExitingCodeBlock = false
            Note over User,DOM: ✅ 光标成功移出代码块
        else 不在边界
            Keyboard-->>Browser: 不处理
            Note over Browser: 浏览器在代码块内移动光标
        end
